# 校园 AI 连接助手 0.3.5

- 先创建 Key，再在校园授权页选择已有 Key 绑定设备；助手不再自动新建、删除或轮换 Key。
- 是否需要助手由学校按校园身份或具体用户设置；免设备限制的用户可直接复制 Key 使用。
- 注册尚未成功时不再展示无效配对码，网络故障分别提示域名解析、证书或超时原因。
- 配合新版网关使用。旧版客户端建议先退出，再安装新版；加密用户数据保留。
